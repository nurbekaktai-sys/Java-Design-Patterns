# Assignment #2: Factory Method & Abstract Factory Patterns

## Course: Software Design Patterns (Astana IT University)

### Description
This project implements two core creational design patterns in Java:
1. **Factory Method (Part A):** Demonstrates transport creation (Truck and Ship) using factory sub-classes.
2. **Abstract Factory (Part B):** Demonstrates a family of related UI components (Windows and Mac GUI toolkits).

### How to Run
1. Open the project in any Java IDE (IntelliJ IDEA, Eclipse, etc.).
2. Navigate to `src/com/assignment2/Main.java`.
3. Run the `main` method to see the execution of both patterns.


### Project Structure
- `src/com/assignment2/factorymethod/` - Factory Method логикасы (Transport, Truck, Ship және фабрикалар)
- `src/com/assignment2/abstractfactory/` - Abstract Factory логикасы (GUI компоненттері және платформа фабрикалары)
- `images/` - Part A және Part B UML диаграммаларының суреттері
